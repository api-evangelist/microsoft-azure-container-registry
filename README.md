# Azure Container Registry (microsoft-azure-container-registry)
Azure Container Registry is a managed, private Docker registry service for storing and managing container images, Helm charts, and OCI artifacts. This collection documents the REST APIs for repository management, image distribution, geo-replication, task-based builds, and webhook notifications used across cloud-native workloads.

## APIs

### Azure Container Registry API
Azure Container Registry provides REST APIs for managing container images, Helm charts, and OCI artifacts. It supports geo-replication, image scanning, task-based builds, webhook notifications, and integration with Azure Kubernetes Service and other container platforms.

**Human URL:** [https://learn.microsoft.com/en-us/rest/api/containerregistry/](https://learn.microsoft.com/en-us/rest/api/containerregistry/)
